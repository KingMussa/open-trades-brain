# Blueprint & Drawing Reading

## Drawing Families (who draws what)

- **M / MP** — mechanical / mechanical piping (your world) · **MD** — mechanical duct · **FP** — fire protection · **P** — plumbing · **E** — electrical · **S** — structural · **A** — architectural
- Sheet order: cover/index → schedules → plans (by level/area) → enlarged plans → sections → **details** → riser diagrams
- A plan view looks DOWN from above; a section is a vertical slice; a detail is a zoomed junction. Grid bubbles (letters one axis, numbers the other) are your address system — always report locations as grid + elevation

## Finding What Governs

1. **Contract drawings** (stamped, current revision) — the law
2. **Specifications** (Div 22 plumbing / Div 23 mechanical / Div 21 fire) — the quality + material law
3. **Approved submittals + shop drawings** — what was actually approved to build
4. **RFI responses + bulletins + CCDs** — changes that modify all of the above
- **Clouds and triangles**: clouded area + revision triangle with number = what changed in this revision. ALWAYS compare against your last set; check the revision block date
- Detail callouts: circle with number-over-letter = detail # on that sheet (or referenced sheet)

## Symbols & Callouts (piping)

- Line types: heavy solid = new work; dashed = existing/demo or hidden; centerline = thin chain
- A pipe callout reads like: **4" CHWS ↑ EL 14'-0"** — size, system, direction (arrow up = rises on the riser), elevation
- Elevation given as **BOI/TOI/COI** (bottom/top/center of insulation or pipe) — mixing these up is a classic 3" error
- Slope arrow points DOWNHILL with the grade noted (1/4"/FT)
- Valves: bowtie = generic; check the symbol legend on the M cover sheet — legends differ per engineer
- Weld/fitting symbols on iso: field weld = flag; shop weld = none

## Isometric Drawings (isos)

- Not to scale — they show ROUTING: every fitting, weld, valve, elevation change in order
- North arrow orients the iso to plan; read from the marked start point
- Spool drawings: each piece gets a spool number matching tags on prefab — check heat numbers on material vs the spool sheet for traceability

## P&IDs

- Process & Instrument Diagram = the SYSTEM LOGIC: every valve, instrument, and control loop, not physical routing
- Instrument bubbles: letters tell function (F=flow, T=temperature, P=pressure, L=level; first letter = measured, second = function — FT = flow transmitter, TE = temperature element)
- Solid line = pipe; dashed = electrical signal; double-slash = pneumatic
- Use the P&ID for valve-tag logic and the plans for physical location — together they answer "what does this valve DO?"

## Field Sketching

- Sketch iso-style: dimension centerline-to-centerline, note BOI/TOI clearly, mark north or a grid line
- Photo BEFORE covering anything; back it up the same day
- Red-line as-builts DAILY — one color, clouded and dated; the closeout package is built from them
